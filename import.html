Import materials

One-off bulk import of the TRAINING MATERIALS folder. Everything is read from your machine and sent straight to Supabase Storage — nothing passes through GitHub.

1. Pick the folder

Choose the TRAINING MATERIALS folder itself. Your browser will ask you to confirm uploading multiple files — that prompt is normal.

2. Run the import

Text extraction reads each PDF's own text layer — fast, and enough for almost everything here. Tick OCR only if some files are scans: it downloads a ~15 MB engine and takes seconds per page. Extraction also back-fills items you imported earlier, so you can re-run this on its own.
